# ADR-0001: Use Next.js for the Clickable MVP

Status: Draft

## Context

The MVP needs a fast local web application with interactive UI, structured components, and a clear path to API integration.

## Decision

Use Next.js, React, TypeScript, and Tailwind CSS for the first clickable MVP.

## Consequences

The project can start as a local demo and later add API routes, OpenAI integration, export features, and persistent storage.
